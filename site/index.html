Features

Feels like a Windows PC. Lives on your Mac.

DirectX 12 → Metal

D3DMetal is built for CrossOver's flavor of Wine. MacX bridges it onto current, upstream Wine 11.

DirectX 9, 10 & 11

DXMT translates DirectX 11 straight to Metal; DXVK goes through Vulkan and MoltenVK. Pick either per game.

A Windows drive on your Desktop

A MacX folder on your Desktop is drive W: in Windows. Drop in a game folder, .exe, installer, .iso or .zip and it's ready to play, install, mount or unpack.

Steam & launchers that work

Steam for Windows, and the Rockstar Games Launcher, with their window-drawing quirks fixed.

Smart per-game defaults

MacX reads which DirectX version each program uses and picks the right engine. Override engine, graphics and launch options per game.

FPS overlay built in

Flip on Apple's Metal HUD from This PC to see frame rate and frame times in any game. Check & repair keeps the setup healthy after updates.

How it works

Six gaps between Wine 11 and D3DMetal. Six bridges.

Apple's D3DMetal expects a differently built Wine, so MacX bridges six differences: four for D3DMetal itself, two more for GTA V Enhanced. The details are technical; every fix is in the open.

  1. 1

    A removed Wine function

    D3DMetal imports __wine_unix_call, which Wine 11 dropped. A tiny ntdlx.dll brings it back, and D3DMetal's import tables are patched to use it.

  2. 2

    The Mac driver's function table

    D3DMetal looks for CrossOver's macdrv_functions table. A Wine patch exports the full 10-slot table in the layout it expects.

  3. 3

    The thread register (GSBASE)

    The hard one. Wine 11 switches %gs to the Windows TEB; D3DMetal's native code needs it on macOS's TSD. A patched ntdll runs in "CrossOver mode".

  4. 4

    Shared state

    Every D3DMetal .so is the same library. Symlinks, not copies, so dxgi and d3d12 share one dispatch table.

  5. 5

    The DirectX 12 Agility SDK

    GTA V Enhanced wants D3D12GetInterface and a loaded d3d12core.dll. A d3d12.dll wrapper provides both.

  6. 6

    Overlay hook validation

    Rockstar's overlay checks that queue methods are real Windows memory. The wrapper points them at forwarding thunks that pass the check.

Install

Four steps, once.

You'll need

  • An Apple silicon Mac (tested on an M4)
  • macOS 14 Sonoma or newer
  • Rosetta 2
  • Homebrew, which also installs Apple's Command Line Tools (MacX needs their Python 3)
  • About 4 GB free, plus room for your games
  • Apple's Game Porting Toolkit (free), which supplies D3DMetal

MacX never downloads or ships anything from Apple. D3DMetal is copied from your Game Porting Toolkit install.

  1. Install Game Porting Toolkit and Rosetta

    You need Homebrew first (it also installs Apple's Command Line Tools). Then, in Terminal, this puts Game Porting Toolkit.app (Gcenx's packaging of Apple's toolkit) in Applications, where MacX looks for it.

    softwareupdate --install-rosetta --agree-to-license brew install --cask gcenx/wine/game-porting-toolkit

  2. Download MacX

    Open the .dmg and drag MacX to Applications.

    Download for Mac

  3. Open it the first time

    MacX is free, so it isn't notarized by Apple (that needs a paid developer account), and macOS warns once.

    • macOS 15 Sequoia and newer: open MacX, click Done, then go to System Settings → Privacy & Security, scroll down and click Open Anyway.
    • macOS 14 Sonoma: right-click MacX → Open → Open.

    Still blocked? Run this once:

    xattr -dr com.apple.quarantine /Applications/MacX.app

  4. Let setup finish, then play

    The setup screen checks your Mac and installs the engines (a few minutes, about 1.5 GB, all pinned and checksum-verified). Then start Steam from the Steam tab, or drop a game into the MacX folder on your Desktop (macOS may ask to let MacX use your Desktop folder; allow it). For DirectX 12 games, MacX picks D3DMetal automatically.

FAQ

Questions, answered.

Is MacX free?

Yes. MacX is free and open source under the MIT license. The engines it builds on (Wine, DXVK, DXMT) are open source too.

Why do I need Apple's Game Porting Toolkit?

D3DMetal, Apple's DirectX 12 → Metal translator, comes with Game Porting Toolkit and can't be redistributed. MacX imports it from your own install on first setup. DirectX 9–11 games can also run on DXMT or DXVK.

Is it safe to run?

All of MacX's code is public on GitHub. Its downloads (Gcenx's Wine 11 build, DXVK-macOS, DXMT) are pinned to exact versions and checked against SHA-256 checksums before use. Each release lists the .dmg's checksum so you can verify it.

Why does macOS warn me when I open it?

Apple only skips that warning for apps notarized through a paid developer account. MacX is ad-hoc signed instead. The steps above let it open; you only need to do it once.

Which games work?

GTA V Enhanced (DirectX 12, via Steam) is the game tested end to end, plus DirectX 11 and 12 test programs. Other games may or may not work. Anti-cheat that needs a Windows kernel driver won't. Tell us what you try on GitHub Issues.

Will it work on an Intel Mac?

No. D3DMetal and MacX's engine target Apple silicon (M1 and later).

How do I see my frame rate?

Turn on Show FPS overlay in games in MacX's This PC tab. It uses Apple's Metal HUD, and takes effect the next time Steam starts.
